Lumina: Real-Time Affective Computer Vision & HUD Presenter Coaching

An affective computing layer turning standard laptop webcams into real-time presentation coaching systems. Co-architected the frontend and HUD rendering pipeline: a transparent, always-on-top PyQt6 overlay, 468-point 3D facial mesh gaze tracking, 33-point skeletal kinesic variance detection, and WebRTC VAD cognitive stall probes via Groq LLM streaming.

01 // MOTIVATION

The Challenge

Eliminating blind spots in technical presentations without hardware bloat.

During high-stakes technical presentations, interviews, and remote defenses, presenters suffer from unconscious kinesic breakdowns: rapid pacing, nervous wrist fidgeting, breaking eye contact with the camera lens, and cognitive stalls during difficult transitions.

Existing public speaking tools rely on intrusive wearables (smartbands, chest straps), expensive multi-camera studio rigs, or post-hoc video recordings that deliver reports hours after the presentation is over.

Design Objective: Build an affective computing layer that operates strictly on standard laptop webcams with zero external hardware, surfacing non-disruptive, real-time feedback through a transparent Heads-Up Display (HUD) floating directly over active video calls or presentation decks.
02 // ARCHITECTURE

HUD Architecture

Decoupling heavy CV pipeline inference from Real-time PyQt6 GUI rendering.

The central engineering challenge was preventing heavy computer vision processing (468-point face mesh + 33-point pose estimation) from causing frame drops or stuttering in the desktop overlay.

Single Source of Truth (`state.py`)

The HUD overlay UI operates strictly as an immutable consumer. It reads from TelemetryState.snapshot() via a 16ms QTimer tick and never writes back to the vision or audio pipelines, eliminating race conditions.

Zero-Chrome Frameless Overlay

Constructed via Qt.WindowType.FramelessWindowHint | Qt.WindowType.WindowStaysOnTopHint with translucent RGBA background composition, allowing presenters to see slide decks and Zoom calls through the HUD.

03 // UI DESIGN

HUD Custom Widgets

Custom QPainter telemetry gauges engineered from first principles.

Rather than standard stock widgets, the overlay features custom vector widgets implemented in hud/overlay.py:

1. Circular StabilityGauge with Harmonic Glow

Renders a 270-degree circular arc ($120 \times 120$ px) measuring overall presenter stability. Implements smooth velocity interpolation: self.value += (self.target_value - self.value) * 0.1. When high kinesic entropy or wrist fidgeting is detected, the gauge transitions from calm cyan to pulsing red with an alpha breathing cycle ($150 + 105 \sin(\text{phase})$).

2. 2D Radar GazeTracker & Confidence Gate

Maps head yaw and pitch into a normalized radar reticle. When head pose drifts beyond calibrated thresholds, surfaces a prominent "WARN: HOLD" confidence gate warning the presenter to re-engage with the camera lens.

3. Animated Probe Notifications

When speech stall detection triggers, prompts fade smoothly into the HUD via a sinusoidal alpha ramp and automatically dismiss once verbal cadence resumes.

04 // COMPUTER VISION

Signal Processing

Positional variance, iris tracking, and kinesic entropy estimation.

Temporal Variance Fidget Detection (`fidget_detector.py`)

Computes 3D coordinates for left wrist (index 15) and right wrist (index 16) from MediaPipe Pose. Coordinates are pushed into a 30-frame circular buffer ($\sim 1.0\text{s}$ at 30 FPS) with a 5-frame moving average smoothing buffer. Positional variance is calculated across the sliding window: 

/* Wrist Variance Detection Logic */
var_left = np.var(left_wrist_buffer, axis=0).sum()
var_right = np.var(right_wrist_buffer, axis=0).sum()
is_fidgeting = (var_left > threshold) or (var_right > threshold)
Iris Gaze & Perspective-n-Point (PnP) Head Pose

Utilizes 468 3D landmarks from MediaPipe Face Mesh. Computes the geometric ratio between iris centroids and eye corner bounds alongside 3D head pose orientation (pitch, yaw, roll) via the Perspective-n-Point algorithm.

05 // SPEECH & AI

Cognitive Stall AI

Detecting presentation silence and streaming real-time coaching questions.

The audio subsystem buffers live microphone frames into WebRTC Voice Activity Detection (VAD). When verbal activity transitions into sustained silence exceeding the calibrated stall threshold ($>2.5\text{s}$), Lumina activates its real-time probe engine: 

- WebRTC VAD: Classifies 20ms audio frames into speech vs. silence.
- Stall Detection: Accumulates contiguous non-speech frames; triggers stall event at 2.5s.
- Groq Llama Streaming: Asynchronously transmits presentation script context and recent speech to Groq.
- Sub-500ms Latency: Synthesizes live audience-style follow-up questions or transition cues.
- Real-Time Script Tracking: Uses pdfplumber to parse slide notes and highlight progress.
06 // TOOLING

Mission Control

20KB desktop launcher providing terminal-free calibration and control.

To make Lumina immediately usable for non-technical presenters, I co-developed launcher.py, a dark-themed desktop mission control application featuring:

Camera Feed Preview

Live OpenCV video window with device index selector and real-time FPS readout to verify lighting and camera positioning.

Microphone Diagnostics

Interactive audio dialog with live RMS volume meter and VAD sensitivity calibration to eliminate background air-conditioning noise.

Script Parser & Uploader

Drag-and-drop ingestion of presentation scripts in PDF or TXT format via pdfplumber, parsing text into cue cards.

One-Click Calibration

5-second resting baseline routine capturing the presenter's natural posture and neutral camera gaze angle before launching.
